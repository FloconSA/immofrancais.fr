# ImmoFrançais

Site vitrine immobilier : https://immo-francais.fr

## Technique
* React 19, React Router 7, Tailwind CSS 3, Vite 7
* Annonces servies par un CMS Strapi 5 (hébergé sur Railway)
* Formulaire de contact envoyé avec EmailJS
* Carte : géocodage et Plan IGN (Géoplateforme)

## Commandes
* `npm run dev` : lancer le site en local
* `npm run build` : vérifier et construire le site

## Mise en ligne
* Code hébergé sur GitHub, publié par Netlify à chaque envoi sur `master`
* Chaque pull request reçoit une adresse de test Netlify

## Comptes
EmailJS, GitHub, Netlify, Railway
